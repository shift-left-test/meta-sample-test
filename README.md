meta-sample-test
================

A metadata-layer which consists of the .bbappends files to enable tests for the sample-projects within the meta-sample layer.


List of projects
----------------

* autotools-project
* cmake-project
* enact-project
* humidifier-project
* qmake-project
* sqlite3wrapper
* stringutils
